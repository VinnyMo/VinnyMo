# Hi, I'm Vinny

This is a collection of tools, games, and experiments I've worked on. Some are newer projects; others are a look back at how I started. Each repository has its own scope and rough edges.

## Explore the projects

### Tools and web experiments

- **[Ubuntu Maintenance](https://github.com/VinnyMo/ubuntuMaintenance)** — A Rust CLI for Ubuntu maintenance, with interactive menus, update modes, scheduling, and logs. The earlier C implementation is still part of its history.
- **[Agent Bridge](https://github.com/VinnyMo/agent-bridge)** — A public message-board project with REST and MCP interfaces for AI agents.
- **[InPlainSight](https://github.com/VinnyMo/inplainsight)** — An experimental file-to-PNG encryption and recovery workflow. Its README explains the server-side recovery requirements and limitations.

### Games and puzzles

- **[Hex Game Prototype](https://github.com/VinnyMo/hex-game-prototype)** — Multiplayer territory expansion on a hex grid, built with Node.js, Socket.IO, and SQLite.
- **[The Enter Game](https://github.com/VinnyMo/ti-enter-game)** — A browser showcase of a TI calculator game, with original assets and decoded TI-BASIC source preserved alongside it.
- **[cicadaCrypt](https://github.com/VinnyMo/cicadaCrypt)** — A small Python exploration of rune transliteration and Atbash mappings for *Liber Primus*.

### Primes and earlier work

- **[Fun With Primes](https://github.com/VinnyMo/fun_with_primes)** — An interactive browser app for exploring primes, alongside the older C experiments that led into it.
- **[Original Fun With Primes](https://github.com/VinnyMo/funWithPrimes)** — C and early JavaScript experiments in prime generation, gaps, and natural decomposition.
- **[High-school projects](https://github.com/VinnyMo/highSchool_Yoink)** — A preserved collection of early projects and calculator work.

The READMEs are the best starting point for setup instructions, project history, and current limitations.
